### ARC-004 固化 PWM 所有权和三级仲裁

**需求来源**：`SRC-A1`、`SRC-A2`、`SRC-A3`、`SRC-U2`、`SRC-GAP`。

- [x] 明确 Stateflow 只产生 `SupervisorPwmRequest`，不直接绕过快速保护控制最终 PWM。
- [x] 快环产生 `FastInterlock`，用于过流和测量无效等快速禁止条件。
- [x] 预留硬件比较器/驱动器门极关断输入 `HardwareGate`。
- [x] 在模型中只保留一个最终 PWM 仲裁点，公式固定为：

  `FinalPwmEnable = SupervisorPwmRequest && FastInterlock && HardwareGate`

- [x] 故障态禁止使用“占空比 0.5”代替真实 PWM 关断；平均值对象可在关断路径内部映射到零线电压。
- [x] 定义 PWM 关闭、重新使能、故障锁存和复位的唯一所有者。

**依赖**：ARC-003。

**验收标准**：所有 PWM 路径都经过同一仲裁点；任一禁止源均可独立关断；仿真与生成代码不存在绕过仲裁的占空比输出。

**执行结果（2026-08-31）**：拆分 `Fast_Protection_100us`、`Fault_Latch_Manager_100us` 和唯一 `Final_PWM_Arbiter_100us`。故障位 0～6/主码 1～7 固定为急停、驱动故障、过流、测量无效、过速、欠压、过压。Stateflow 只输出监督请求；控制器 Duty 保持原始 SVPWM 请求；仅 Harness 的 `Average_Plant_Enable_Map` 在平均值对象内部把禁用映射为 0.5。急停、驱动故障、过流、测量无效的模型关断延迟均为 0 us，位码分别为 1/1、2/2、4/3、8/4；HardwareGate 可独立同周期关断和恢复；ERT 代码检查 PASS。

**依赖**：ARC-004。

**验收标准**：模型采样时间着色和自动检查显示任务归属正确；快慢环之间无隐式速率转换；测试可测得并证明响应延迟满足合同。

**执行结果（2026-08-31）**：模型顶层和手册均给出组件级任务表：100 us 快任务设计预算 70 us，1 ms 慢任务预算 400 us，明确周期、相位、输入和消费者；预算是分配值，目标 WCET 实测仍归 M9。17 个命名 Rate Transition 通过自动类型检查，慢到快保护量采用“数据完整、最小延迟”配置；结构门禁确认旧数据类型转换边界和分散 PWM 门控均不存在。实测 Stop 状态响应 0.7 ms，软件快速禁止 0 us，全部满足合同；专项结构、MIL、代码生成总门禁 PASS。
